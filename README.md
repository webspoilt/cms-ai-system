## 🎯 Overview

AI-powered Content Management System that generates, optimizes, and manages content using OpenAI's GPT models.

---

## ✨ Features

- 🤖 **AI Content Generation** - Auto-generate articles
- ✍️ **Smart Editing** - AI-powered suggestions
- 🔍 **SEO Optimization** - Automatic SEO improvements
- 🌐 **Multi-language** - Translate content
- 📊 **Analytics** - Content performance tracking

---

## 🚀 Quick Start

```bash
git clone https://github.com/webspoilt/cms-ai-system.git
cd cms-ai-system
npm install
cp .env.example .env
# Add your OpenAI API key
npm run dev
```
